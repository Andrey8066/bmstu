# ЛР1. Генетический алгоритм — вопросы на защите

## 1. Как G2 выбирает победителя? Что происходит при равенстве значений функции?

Функция `G2` реализует турнирный отбор. Из случайно выбранных участников турнира побеждает тот, у кого значение целевой функции минимально, поскольку задача заключается в минимизации.

В моей программе размер турнира равен 3 (`cfg.tournament = 3`). Если значения целевой функции совпадают, выбирается первый участник в строке `candidates`.

## 2. Как вычисляются два потомка в вашем варианте? Покажите расчёт одной координаты.

В варианте 3 используется арифметическое скрещивание. Сначала выбирается одно случайное число $\alpha=u(1)$, которое используется для всех координат обоих потомков.

Формулы скрещивания:

$$
a_j=\alpha p_j+(1-\alpha)q_j
$$

$$
b_j=(1-\alpha)p_j+\alpha q_j
$$

Например, пусть $p_j=2$, $q_j=6$, а $\alpha=0.25$. Тогда:

$$
a_j=0.25\cdot2+0.75\cdot6=5
$$

$$
b_j=0.75\cdot2+0.25\cdot6=3
$$

Таким образом, координаты потомков равны 5 и 3. Оба потомка рассчитываются по исходным родителям.

После скрещивания к каждому потомку может применяться мутация.

## 3. Чем pm отличается от величины изменения координаты? Что получится при pm = 0?

Параметр `pm` — это вероятность мутации каждой координаты потомка. Он определяет, как часто координаты будут изменяться, но не задаёт величину изменения.

В моём варианте используется случайная замена: если координата выбрана для мутации, ей присваивается случайное значение в пределах `[lb(j), ub(j)]`.

При `pm = 0` условие `u(j) < pm` никогда не выполняется, поэтому мутации не будет. Потомки будут формироваться только за счёт скрещивания либо копирования родителей, если скрещивание не произошло.

## 4. Зачем в готовом коде сохраняются две элитные особи?

Элитизм позволяет перенести две лучшие особи текущего поколения в следующее поколение без изменений. В программе это задаётся параметром `cfg.elite = 2`.

Это необходимо, чтобы уже найденные хорошие решения не были потеряны из-за скрещивания или мутации. Элитизм помогает сохранять достигнутое качество решения, хотя сам по себе не гарантирует нахождение глобального минимума.

## 5. Какой pm оказался удачнее для каждой функции? Насколько согласованы итоги пяти запусков? Почему выводы для двух функций могут различаться?

В эксперименте сравниваются три значения вероятности мутации: `pm = 0.02`, `pm = 0.10` и `pm = 0.30`. Для каждой целевой функции выполняется пять независимых запусков.

Лучшим следует считать значение `pm`, при котором итоговое значение целевой функции `bestF` оказывается меньше. Согласованность запусков оценивается по разбросу итоговых значений: чем меньше разброс, тем стабильнее результат.

Заранее нельзя утверждать, какое значение `pm` окажется лучшим, поскольку результат зависит от фактических запусков. Для точного ответа необходимо посмотреть полученные графики и итоговые значения `bestF`.

Выводы для двух функций могут различаться, потому что у них разные свойства ландшафта целевой функции. У функции Розенброка узкая изогнутая долина минимума, а у функции Растригина много локальных минимумов. Поэтому им могут требоваться разные сочетания локального улучшения решений и исследования новых областей пространства поиска.

**Итог:** по результатам эксперимента нужно указать фактически лучшее значение `pm` для каждой функции и оценить устойчивость результатов пяти запусков.
